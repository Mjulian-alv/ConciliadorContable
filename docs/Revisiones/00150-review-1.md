## Hallazgo 1 — alto — Un HTML dañado puede volver cuadrática la regex
`SapListReader.Cell` no tenía tiempo máximo y un `<nobr>` sin cierre repetido obliga a reescanear hasta el final del archivo (20 MB permitidos).

**Qué se hizo:** la regex tiene `matchTimeout` de 5 s y el timeout se informa como «el HTML está dañado». Prueba nueva con 150.000 celdas sin cierre: termina con `ImportException`, sin colgarse. Comentario TAREA 00150 Línea 1.

## Hallazgo 2 — medio — Las celdas se acumulaban antes de aplicar el tope de filas
Un archivo de 20 MB podía generar millones de entradas antes de llegar a `MaxRows`.

**Qué se hizo:** tope de 1.000.000 de celdas mientras se lee (`MaxCells`), con el mismo comentario de versionado.
